## Application Source Code (Private)

The application source code has been moved to a private repository 
to reflect real-world security practices.

This project focuses on:

- Microservices architecture (Node.js + Java + Angular)
- Containerization with Docker
- CI pipeline using GitHub Actions
- GitOps-based CD using ArgoCD
- Kubernetes (k3s) cluster deployment
- Observability using Prometheus & Grafana
- Security scanning using Trivy
